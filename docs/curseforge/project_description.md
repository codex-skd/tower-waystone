## Tower Waystone

Stone towers with waystones scattered across your world — activate them and teleport between towers with the [Waystones mod](https://www.curseforge.com/minecraft/mc-mods/waystones).

### 4 Biome-Themed Variants

| Variant | Biomes |
|---------|--------|
| **Normal** | Plains, forests, meadows, savannas, windswept hills, cherry groves |
| **Sandy** | Deserts, badlands |
| **Mossy** | Jungles, swamps, mangroves, taigas |
| **Snowy** | Frozen peaks, snowy plains, ice spikes, groves |

Each tower blends naturally with its environment — no more sandy towers in green fields.

### Features

- Towers generate with a built-in waystone ready to activate
- Waystones get unique fantasy names (Whispering Peak, Stormwatch, Iron Sentinel...)
- Compatible with `/locate structure tower_waystone:<variant>`
- 4 independent structure sets, each spaced ~64 chunks apart
- Waystones mod required — towers won't generate without it

### Requirements

- **NeoForge** 26.1.2+
- **[Waystones](https://www.curseforge.com/minecraft/mc-mods/waystones)** 26.1+
