<h2>v1.0.6 - Configurable waystone light beam</h2>

<h3>Added</h3>
<ul>
<li><strong>Waystone light beam</strong>: every waystone generated by a tower now renders a vertical beacon-style light beam above it (client-side, purely visual). Independent from the Waystones mod's own renderer - detects waystone blocks via chunk load/unload and reuses vanilla's own beam-drawing routine, so it won't break if Waystones changes its internals.</li>
<li><strong>Real, working config</strong>: <code>config/tower_waystone/waystone_beacon.json</code> with <code>enabled</code> (on/off), <code>color</code> (RGB 0-255) and <code>height</code> (beam height in blocks).</li>
</ul>

<h3>Notes</h3>
<blockquote>Purely client-side and visual. Does not affect world generation, saved data, or dedicated server behavior.</blockquote>
