<h2>v1.0.0 - First stable release for Minecraft 26.2</h2>

<h3>Added</h3>
<ul>
<li>First stable release for Minecraft 26.2</li>
<li>8 tower variants: 4 Overworld (Normal, Sandy, Mossy, Snowy) + 2 Nether (Blackstone, Brick) + 2 End (Stone, Purpur)</li>
<li>Custom dimension support via <code>config/tower_waystone/custom_dimensions.json</code></li>
<li>Automatic waystone naming with fantasy names</li>
</ul>

<h3>Notes</h3>
<blockquote>This is the first stable release for Minecraft 26.2. All features from 26.1.2 have been ported and improved with Nether/End variants and custom dimension support.</blockquote>
