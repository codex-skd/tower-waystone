<h2>v1.0.5 - New tower family + legacy waystone block fix</h2>

<h3>Added</h3>
<ul>
<li><strong>9 new tower variants</strong> ported from <a href="https://www.curseforge.com/minecraft/mc-mods/simply-waystone-tower">Simply Waystone Tower</a> (MCreator, Forge 1.20.1), adapted to this mod's jigsaw structure system:
<ul>
<li><code>simply_waystone_tower</code> (3 variants) — generic stone towers, temperate biomes (plains, forests, savannas, windswept hills).</li>
<li><code>simply_waystone_tower_ruins</code> (4 variants, some with a mob spawner) — jungles, swamps, taigas, dark forests.</li>
<li><code>simply_waystone_tower_pillager</code> (2 variants) — pillager-themed towers, outpost-style biomes (plains, savannas, deserts, snowy plains/taiga).</li>
</ul>
</li>
</ul>

<h3>Fixed</h3>
<ul>
<li><strong>Missing waystone on the 4 original towers</strong>: <code>waystone_tower</code>, <code>mossy_waystone_tower</code>, <code>sandy_waystone_tower</code> and <code>snowy_waystone_tower</code> referenced the legacy block IDs <code>waystones:waystone</code>, <code>mossy_waystone</code> and <code>sandy_waystone</code>, which no longer exist in the Waystones version this mod depends on (that version only registers material-named variants). As a result these towers generated with no real waystone block — the game silently treated the unknown ID as air. Remapped to the current IDs: <code>andesite_waystone</code>, <code>mossy_andesite_waystone</code>, <code>sandstone_waystone</code>.</li>
</ul>

<h3>Notes</h3>
<blockquote>If you already have a world generated with the old towers, previously-placed structures are not retroactively fixed — only newly generated ones use the corrected block.</blockquote>
