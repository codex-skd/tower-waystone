<h2>v0.0.0-beta.2 - Nether &amp; End tower variants</h2>

<h3>Added</h3>
<ul>
<li><strong>Nether blackstone towers</strong> — generate in all Nether biomes using polished blackstone and shroomlight</li>
<li><strong>Nether brick towers</strong> — generate in all Nether biomes using nether bricks and crimson nylium</li>
<li><strong>End stone towers</strong> — generate in all End biomes using end stone bricks</li>
<li><strong>End purpur towers</strong> — generate in all End biomes using purpur blocks</li>
<li>All variants use block-replacement processors over the existing tower structure</li>
</ul>
