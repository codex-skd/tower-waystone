<h2>v1.2.0 - Custom dimension support</h2>

<h3>Added</h3>
<ul>
<li><strong>Custom dimension support</strong> — configure <code>config/tower_waystone/custom_dimensions.json</code> to generate towers in any modded dimension</li>
<li>Block validation with automatic fallback — invalid blocks fall back to defaults, server won't crash</li>
<li>Full documentation in <code>docs/custom_dimensions.md</code> with examples</li>
</ul>
