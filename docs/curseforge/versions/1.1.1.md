<h2>v1.1.1 - Removed the Simply Waystone Tower variants</h2>

<blockquote>This build ships <strong>only the Stalking Dragons&ndash;built towers</strong>. The derived <em>Simply Waystone Tower</em> structures have been removed.</blockquote>

<h3>Removed</h3>
<ul>
<li><strong>Simply Waystone Tower structures</strong>: the three families derived from <a href="https://www.curseforge.com/minecraft/mc-mods/simply-waystone-tower">Simply Waystone Tower</a> by <em>amefurashi1976</em> (All Rights Reserved content) and all of their worldgen have been removed &mdash; 9 <code>.nbt</code> templates (<code>simply_waystone_tower_1/2/3</code>, <code>simply_waystone_tower_broken_2/3/4/5</code>, <code>simply_waystone_tower_pillager_1/2</code>) plus 12 JSON files (<code>structure</code>, <code>structure_set</code>, <code>template_pool</code> and <code>has_structure</code> biome tags for <code>simply_waystone_tower</code>, <code>simply_waystone_tower_ruins</code> and <code>simply_waystone_tower_pillager</code>).</li>
<li>The mod again generates only its own towers: Normal, Sandy, Mossy, Snowy, Nether Blackstone / Nether Brick and End Stone / End Purpur.</li>
<li>No code changes &mdash; the Java structure registry is generic and never referenced these structures by name. The native <code>.nbt</code> templates are untouched.</li>
</ul>

<h3>Notes</h3>
<blockquote>Existing worlds keep any Simply Waystone Tower blocks already generated, but Minecraft will log warnings about the missing <code>tower_waystone:simply_waystone_tower*</code> structure IDs. This does not affect gameplay and does not crash.</blockquote>
