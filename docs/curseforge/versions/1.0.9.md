<h2>v1.0.9 - Critical crash fix</h2>

<blockquote><strong>v1.0.8 crashes on startup.</strong> Update to v1.0.9 immediately if you installed v1.0.8.</blockquote>

<h3>Fixed</h3>
<ul>
<li><strong>Game crashed on load (regression introduced in 1.0.8)</strong>: the waystone detection tick handler was registered on <code>ClientTickEvent</code>, an abstract class - NeoForge throws an <code>IllegalArgumentException</code> when a listener is registered on an abstract event class, which prevented the mod from loading and crashed the client during setup. Fixed by registering on <code>ClientTickEvent.Post</code>, the concrete subclass fired once per client tick.</li>
</ul>
