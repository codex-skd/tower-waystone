<h2>v1.0.17 - API integration & biome fix</h2>

<h3>Fixed</h3>
<ul>
<li><strong>Waystone naming now works</strong> — uses Waystones API directly (<code>WaystonesAPI.getWaystoneAt</code> + <code>MutableWaystone.setName</code>)</li>
<li><strong>No longer overwrites existing names</strong> — checks <code>hasName()</code> before naming; player-placed waystones are never renamed</li>
<li><strong>Biome tags refined</strong> — each tower variant now only generates in thematically appropriate biomes:</li>
<ul>
<li>Sandy → deserts, badlands</li>
<li>Mossy → jungles, swamps, taigas</li>
<li>Snowy → frozen peaks, snowy plains, ice spikes</li>
<li>Normal → plains, forests, savannas</li>
</ul>
<li>Removed <code>plains</code> from sandy/mossy/snowy biome tags — no more sandy towers in green fields</li>
</ul>

<h3>Changed</h3>
<ul>
<li>Added <code>waystones-neoforge-26.1.2-26.1.2.9.jar</code> as compile dependency from <code>libs/</code></li>
<li>Switched from reflection to direct API imports for Waystones integration</li>
</ul>
