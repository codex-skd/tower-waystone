<h2>v1.0.10 - Initial native port</h2>

<h3>Fixed</h3>
<ul>
<li>Replaced MCreator template with native NeoForge 26.1.x project</li>
<li>Structures now generate correctly using data-driven JigsawStructure (<code>terrain_adaptation: none</code>, <code>heightmap: OCEAN_FLOOR_WG</code>)</li>
<li>Removed broken StructureProcessor — was blocking structure generation entirely</li>
<li>Template pools simplified to use <code>"minecraft:empty"</code> processor</li>
</ul>

<h3>Added</h3>
<ul>
<li>4 tower variants: normal, mossy, sandy, snowy with NBT structure templates</li>
<li>Compatible with <code>/locate structure tower_waystone:&lt;variant&gt;</code></li>
<li>Waystones declared as required dependency in <code>neoforge.mods.toml</code></li>
</ul>

<h3>Known Issues</h3>
<blockquote>Waystone naming does not work in this version (fixed in 1.0.17).</blockquote>
