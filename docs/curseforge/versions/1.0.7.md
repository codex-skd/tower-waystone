<h2>v1.0.7 - Tower placement and beam height fixes</h2>

<h3>Fixed</h3>
<ul>
<li><strong>New towers placed wrong / spawning underwater</strong>: the <code>simply_waystone_tower</code>/<code>_ruins</code>/<code>_pillager</code> structures had their floor directly at <code>y=0</code>, without the 5-block dirt basement the mod's own towers have (which use <code>start_height.absolute = -6</code>). Reusing that same offset buried the 3 new tower families about 6 blocks into the terrain. Fixed to <code>start_height.absolute = 0</code> for all three.</li>
<li>Removed <code>minecraft:swamp</code> and <code>minecraft:mangrove_swamp</code> from <code>simply_waystone_tower_ruins</code>'s biome tag - those biomes have shallow surface water pools that still spawned the tower underwater even with the corrected offset.</li>
<li><strong>Light beam too short</strong>: the configurable beam added in 1.0.6 cut off just a few blocks above the waystone (<code>height</code> field, defaulting to 6). The beam's starting point is now anchored to the top of the waystone block (which is 2 blocks tall), and the default <code>height</code> is raised to <strong>100</strong> blocks - much more visible in practice. The field stays configurable in <code>waystone_beacon.json</code>; an invalid value (<code>&lt;= 0</code>) falls back to the default.</li>
</ul>

<h3>Notes</h3>
<blockquote>The beam height fix is purely client-side and visual. Does not affect world generation, saved data, or dedicated server behavior.</blockquote>
