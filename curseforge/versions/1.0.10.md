# Tower Waystone 1.0.10

### Fixed
- Replaced MCreator template with native NeoForge 26.1.x project
- Structures now generate correctly using data-driven JigsawStructure (terrain_adaptation: none, heightmap: OCEAN_FLOOR_WG)
- Removed broken StructureProcessor — was blocking structure generation entirely
- Template pools simplified to use `"minecraft:empty"` processor

### Added
- 4 tower variants: normal, mossy, sandy, snowy with appropriate NBT structure templates
- Compatible with `/locate structure tower_waystone:<variant>`
- Waystones declared as required dependency in neoforge.mods.toml

### Known Issues
- Waystone naming does not work in this version (fixed in 1.0.17)
