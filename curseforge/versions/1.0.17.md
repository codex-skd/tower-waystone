# Tower Waystone 1.0.17

### Fixed
- **Waystone naming now works** — uses Waystones API directly (`WaystonesAPI.getWaystoneAt` + `MutableWaystone.setName`)
- **No longer overwrites existing names** — checks `hasName()` before naming; player-placed waystones are never renamed
- **Biome tags refined** — each tower variant now only generates in thematically appropriate biomes:
  - Sandy → deserts, badlands
  - Mossy → jungles, swamps, taigas
  - Snowy → frozen peaks, snowy plains, ice spikes
  - Normal → plains, forests, savannas
- Removed `plains` from sandy/mossy/snowy biome tags — no more sandy towers in green fields

### Changed
- Added `waystones-neoforge-26.1.2-26.1.2.9.jar` as compile dependency from `libs/`
- Switched from reflection to direct API imports for Waystones integration
